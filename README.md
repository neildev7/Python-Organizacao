# 🗂️ Organizador Automático de Arquivos

Este projeto implementa um **script em Python** para organizar arquivos em pastas de forma automática, de acordo com suas extensões.  
O objetivo é facilitar a gestão de diretórios, separando arquivos em categorias como imagens, documentos, planilhas, vídeos, áudios e PDFs.

Este projeto foi desenvolvido como parte do meu aprendizado em **Python**, aplicando conceitos de manipulação de arquivos, automação de tarefas e interação com o sistema operacional.

---

## 📌 Sobre o Projeto

O sistema realiza automaticamente:

- 📂 **Seleção de diretório** através de uma janela interativa  
- 🔎 **Leitura de arquivos** no diretório selecionado  
- 🏷️ **Classificação automática** por tipo de extensão em categorias:  
  - Imagens (`.png`, `.jpg`, `.jpeg`, `.gif`, `.bmp`)  
  - Documentos (`.docx`, `.txt`, `.pptx`)  
  - Planilhas (`.xlsx`, `.xls`, `.csv`)  
  - Vídeos (`.mp4`, `.mkv`, `.mov`, `.avi`)  
  - Áudios (`.mp3`, `.wav`, `.aac`, `.flac`)  
  - PDFs (`.pdf`)  
- 📦 **Criação de pastas** caso ainda não existam  
- 🚚 **Movimentação automática** dos arquivos para as pastas corretas  
- ✅ **Mensagem final** confirmando a conclusão da organização

## 📂 Estrutura do Projeto

- `main.py` – Script principal de organização  

---

## ▶️ Como Usar

1. Clone o repositório ou copie o script `organizador.py`.  
2. Execute o script em um ambiente Python ou em um terminal com o comando: python organizador.py
3. Na janela que será aberta, selecione a pasta que deseja organizar.
4. Aguarde a execução e confira os arquivos organizados automaticamente em pastas separadas.
